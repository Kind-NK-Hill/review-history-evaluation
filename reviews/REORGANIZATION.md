# 第 0.5.0 版重组说明

本次以第 0.3.0 版的章节层级和便于定位定义的方式为结构参照，以第 0.4.0 版正文为行文底稿。两版此前的英文与中文成品保持原样。

## 读者定位

假定读者掌握微积分、概率、线性代数及统计推断基础。删除希腊字母读音、求和符号、帽子记号、t 分布形状及一般统计概念的教材式讲解。保留研究对象的定义、实际计算、整群抽样的具体操作、分析目标和模型条件。没有为了简短而删掉数学证明、配对计算、停止模型或已有实证表格。

## 章节与定义入口

1. 第一节先说明教材任务如何成为候选文件，构建与审核各检查什么，问题如何反馈到修改，以及为什么保存这些材料。明确这不是对全部历史采用同一套当前引擎的假定。
2. 第二节独立解释事后整理流程。三次提交贯穿任务、候选、审核记录、端点出现、连接和片段；随后逐项说明原始相邻关系保留、时间定向、优先角色分类、高置信筛选、共享审核端点拼接、失败起点筛选及首次通过截取。
3. 解释 3,231 个证据签名、2,738 个保留原始相邻对、93 个时间歧义对和 2,645 条可定向连接。添加活动分类表与完整片段长度表，逐项核对 465=367+98、367 条边→262 个片段、230 个失败起点→182 个任务→329 个观察步骤→206 次通过/24 次退出。
4. 执行样本先说明问题与用途，再解释 6+8=14 对、28 个端点、两次评估共 28 张历史表，加 7 张构造表得到 35 张表。另行介绍一个定义案例及一个布尔任务，防止把它们相加为独立样本。
5. 后续各章恢复有信息量的标题，新增可定位标签；配对统计明确使用全部 465 条边，318 条图链不等于 367 条高置信边的 262 个过程片段。过程章再次明确“构造完整片段”与“截取实际观察”的区别。
6. 附录 A 提供 31 项定义与方法索引，含章节和页码；附录 B 映射到随附相对目录及公开评估仓库。

## 数学与证据保留

`content_integrity.json` 对两种语言分别核对全部既有展示公式、公式环境、三个命题和证明，以及 16 个实证/数学表格环境。命题中仅删去一处解释 min 符号的句子；数学假设、结论和证明未变。新增加的流程与单位表另行按冻结输入及分类来源核对，不冒充旧表的逐字复制。

所有既有引文保持。英文和中文定位标签一致，新增计数及分析顺序逐项对应。`evidence/SOURCE_MAP.json` 记录本版所带源文件副本及节选；本地保留的 `PREVIOUS_RELEASE_SNAPSHOT.json` 与内容检查共同核对先前三版共 820 个文件没有改变，公开源稿包只附相应检查结果。没有新实验、模型重估、原始数据改写或生产状态变更。

## 构建与分发

两份报告从各自 LaTeX 入口调用 Tectonic 编译。中文使用已记录的 Windows 字体，构建要求明确列在 README；字体不包含在源稿包内。目录迁移测试只检验相同字体环境下的相对路径构建，不声称任意平台和字体具有相同页数。

公开源稿包携带编译源、图件、选定冻结统计材料、来源说明和交付检查，排除带本机执行路径的原始构建日志及内部写作脚本。它并非全部原始执行证据的完整发布包；报告附录与 README 均明确保留这个范围区别。
