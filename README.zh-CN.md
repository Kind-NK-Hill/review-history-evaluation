## 研究内容

十一组概率任务、三种工作配置、两批共66项交付，构成成果和投入比较。按共同数学成果标准，第一批A、B各完成10/11组，C完成11/11组；第二批三种配置均完成11/11组。第二批三项原判定由已交付代码和调用检查纠正，两批的任务说明和运行安排分别披露。

过程研究保存33项第二批主运行的4,054次实际工具调用和179次工具发现，每项从首次检索与首次诊断形成两条记录。数学案例将反馈、修改与最终源码联系起来，包括分布函数表示的适配、辅助证明的转交，以及尚未闭合的局部试验。这66条记录有重叠且终点层次不同，不合并成全体失败恢复率。

## 从哪里开始

1. 先读正文摘要及第4章的一个数学案例。
2. 打开[分布函数表示修订的逐步记录](report-v28/examples/r2-m3-b.zh-CN.md)，对照请求、返回和最终源码。
3. 按[复算说明](report-v28/REPRODUCIBILITY.md)生成结果与时间表，再查看过程统计。
4. 在[工程仓库](https://github.com/Kind-NK-Hill/ProbabilityTheoryFormalization)查看运行演示、审核绑定、修复和状态管理。

```text
python verify_release.py

```
